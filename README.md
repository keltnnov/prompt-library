# 📚 Prompt Library

Личная библиотека промптов: рабочие ассистенты для «Мотордеталь» и промпты для RAG-проекта.

## Структура

```text
prompt-library/
├── README.md                  # Оглавление: таблица всех промптов, статусы и ссылки
├── motordetal/                # Рабочие ассистенты для «Мотордеталь»
│   └── main-assistant.md      # 🔒 временно не публикуется (внешняя проверка)
├── rag-system/                # Промпты для RAG-проекта
│   ├── router-agent.md        # Маршрутизация по ролям (Admin / РОП / ТМ)
│   └── strict-qa.md           # Ответы строго по контексту базы знаний
└── archive/                   # Устаревшие промпты, которые больше не нужны
    ├── crm-assistant.md       # 🔴 заменён main-assistant.md
    ├── audio-transcriber.md   # 🔴 заменён main-assistant.md
    └── kp-generator.md        # 🔴 заменён main-assistant.md
```

## Статусы

| Иконка | Статус | Значение |
|:------:|--------|----------|
| 🟢 | стабильный | Промпт проверен в работе, можно брать как есть |
| 🟡 | черновик | Рабочая версия, требует тестов и доработки |
| 🔴 | устаревший | Перенесён в [archive/](archive/), не использовать |

## Как пополнять библиотеку

1. Новый промпт кладём в нужную папку как `<имя>.md` по шаблону (см. любой существующий файл): YAML-паспорт (frontmatter: `id`, `version`, `status`, `purpose`, `last_updated` — регламент в [.clinerules](.clinerules)) → шапка со статусом → назначение → системный промпт → переменные → критерии качества.
2. Добавляем строку в таблицу оглавления выше.
3. Промпты, которые больше не нужны, переезжаем в `archive/` и меняем статус на 🔴.
