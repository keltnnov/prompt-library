# 🗄 Archive

Устаревшие промпты, которые больше не используются в работе.

Правила:
- Промпт переезжает сюда вместо удаления — пусть остаётся история (наработки могут пригодиться).
- В [оглавлении](../README.md) у него ставится статус 🔴 устаревший.
- Если промпт снова понадобился — возвращаем его в рабочую папку и меняем статус на 🟡/🟢.
